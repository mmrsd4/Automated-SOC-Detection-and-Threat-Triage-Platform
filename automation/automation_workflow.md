\# Automation Workflow



\## Workflow Overview



Splunk alerts trigger Python automation scripts.



The automation performs:

\- IOC extraction

\- Threat intelligence enrichment

\- Severity classification

\- Incident report generation

\- Discord notifications



\---



\# Workflow Steps



1\. Splunk detection triggers

2\. Python script extracts IOC

3\. VirusTotal API queried

4\. AbuseIPDB queried

5\. Severity assigned

6\. Incident report generated

7\. Discord alert sent



\---



\# Automation Outcome



Reduces:

\- manual triage time

\- investigation overhead

\- analyst workload
